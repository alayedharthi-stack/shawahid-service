# بيانات تجريبية أصلية

هذه أمثلة رياضيات للصف السادس عن المعادلات ذات الخطوة الواحدة. الأسئلة والرسم وخطة الأيام أُنشئت لهذه التجربة وليست منقولة من المراجع. مطابقة إصدار المنهج أو فصل دراسي محدد غير متحققة؛ بقيت هذه الحقول فارغة. لا تستخدمها بوصفها توزيعًا رسميًا أو نموذجًا معتمدًا من الوزارة.

`worksheet.json` يحتوي نسخة الطالب. `worksheet.answers.json` مفتاح منفصل. `exam.json` يعيد استخدام محتوى الورقة عمدًا لإثبات استقلال التصميم عن المحتوى، مع درجات إجبارية ومجموع 10؛ مفتاحه `exam.answers.json` يضيف توزيع الدرجات. `weekly-plan.json` مثال قابل للتعديل لا ينقل تواريخ أو دروس الخطة المرجعية.

مقترح بيانات المدرسة والإدارة لا يُؤخذ من النماذج التجارية؛ يملؤهما المعلم من بياناته المعتمدة. SVG الرسم مصدر أصلي قابل للتحرير؛ PNG هو النسخة المضمنة الآمنة للتصدير.
