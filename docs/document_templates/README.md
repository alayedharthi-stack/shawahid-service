# قوالب مستندات شواهد — تجربة v1

ثلاثة قوالب أصلية قابلة للتعبئة: ورقة عمل خفيفة، اختبار بدرجات، وخطة أسبوعية. التصميم منفصل عن أسئلة الأمثلة وإجاباتها. هذه إضافة اختيارية للمعاينة محليًا؛ لا تغيّر مسار واتساب أو حفظ الشواهد أو تخصيص PDF المرفوع، ولا تنشر خدمة أو تتصل بمشروع نحلة.

| القالب | الطباعة | المعاينة |
|---|---|---|
| ورقة العمل | A4 عمودي، عمودان، هوامش 14 مم، الدرجات مخفية افتراضيًا | [الطالب](previews/worksheet.pdf) · [الإجابة](previews/worksheet-answers.pdf) |
| الاختبار | A4 عمودي، عمود واحد، هوامش 14 مم، درجات إلزامية | [الطالب — صفحتان](previews/exam.pdf) · [الإجابة](previews/exam-answers.pdf) |
| الخطة | A4 أفقي، أيام الأسبوع صفوف، ستة أعمدة | [الخطة](previews/weekly-plan.pdf) |

توجد صور PNG لكل صفحة بجانب PDF. عينات الرياضيات للصف السادس أصلية؛ لا تثبت مطابقة طبعة المنهج أو الفصل أو التوزيع الرسمي. لم تُملأ المدرسة والإدارة أو التواريخ من مدارس النماذج المرجعية. اسم المعلم في الأمثلة: تركي عايد الحارثي. لا يوجد شعار وزارة أو ادعاء اعتماد وزاري.

## مواضع الملفات

- `app/templates/documents/v1/`: Jinja وCSS والأجزاء المشتركة وتعريف الحقول `manifest.json`.
- `app/document_templates/`: التحقق، تعبئة HTML، وتصدير PDF مستقل دون وصول شبكي.
- `examples/documents/v1/`: بيانات الأمثلة وملفات الإجابة المنفصلة ورسمة أصلية.
- `app/static/documents/`: خط Noto Sans Arabic ورخصة OFL.
- `scripts/render_document_template.py`: تشغيل محلي دون قاعدة بيانات أو إعداد الخدمة.
- `tests/document_templates/`: اختبارات البيانات والرياضيات والتصدير الحقيقي.

## الاستخدام

من جذر المستودع، بعد تثبيت تبعيات المشروع وChromium الخاص بإصدار Playwright المحدد في `requirements.txt`:

```sh
python -m playwright install chromium
python scripts/render_document_template.py examples/documents/v1/worksheet.json --answers examples/documents/v1/worksheet.answers.json --output-dir preview
python scripts/render_document_template.py examples/documents/v1/exam.json --answers examples/documents/v1/exam.answers.json --output-dir preview
python scripts/render_document_template.py examples/documents/v1/weekly-plan.json --output-dir preview
```

يُخرج الأمر HTML مستقلًا وPDF للطالب، وملفين منفصلين للإجابة عند تمرير `--answers`. يمكن استخدام `--html-only` دون Chromium. عدّل بيانات JSON أو التصميم ثم أعد التوليد؛ لا يوجد محرر مرئي في الخدمة بعد. **HTML وJSON صيغة قابلة للتحرير وإعادة التوليد، وليسا ملف Word أو بديلًا مكافئًا له.** لا يوجد دعم DOCX في هذه التجربة.

واجهة Python:

```python
from app.document_templates import render_document, export_pdf
student_html = render_document(document)  # لا تمرر بيانات الحل
student_pdf = export_pdf(document)
answer_pdf = export_pdf(document, answers=answer_key)
```

## الحقول والقواعد

`profile` يشمل المعلم والمدرسة وإدارة التعليم والمادة والصف والفصل والعام والتاريخ والعنوان والأسبوع وإصدار المنهج. المادة والصف والعنوان مطلوبة؛ ما ينقص يظل فارغًا. لا تُدرج قيمة غير موثقة لإصدار المنهج.

الأسئلة قائمة ذات معرفات فريدة، ونص ومعادلة واختيارات اختيارية وأسطر إجابة ودرجة وجدول وصورة اختيارية. الإجابات ملف منفصل مفاتيحه تطابق معرفات الأسئلة بالضبط. لا توجد حلول مخفية في HTML الطالب. في الاختبار، يلزم مجموع يساوي درجات البنود؛ في الورقة تظهر الدرجات فقط عند `show_marks=true` وتوفير مجموع صحيح.

المعادلة قائمة رموز نصية أو كسر بسيط مثل `{"numerator":"س","denominator":"٥"}`. تُعرض MathML مع عزل الاتجاه. لا يقبل الحقل HTML أو LaTeX تنفيذيًا. تُعقّم النصوص آليًا. الجدول حتى 6 أعمدة و8 صفوف، والصورة PNG مضمنة مع `alt` و`attribution`؛ حقل النسب يظل فارغًا فقط عندما لا يلزم نسب. لا يُجلب عنوان صورة خارجي أثناء التصدير.

تُضاف أرقام الصفحات العربية ورأس استمرار مختصر للصفحات التالية للاختبار داخل PDF في الهامش المحجوز. هذا الرأس والترقيم ليسا ضمن تدفق HTML؛ الطباعة اليدوية للـHTML ليست بديلًا عن `export_pdf`. بيانات الرأس الطويلة التي لا تتسع تتطلب مراجعة يدوية. يفشل التصدير بصراحة عند صورة تالفة أو كتلة تتجاوز ارتفاع الصفحة أو عرضها؛ تبقى مراجعة PDF بصريًا ضرورية، خاصة للمحتوى الطويل والكسور والجداول.

## أصغر ربط لاحق بشواهد

أضف محولًا من بيانات المعلم ونتيجة تحليل معتمدة إلى عقد JSON هذا، ثم شاشة/خطوة مراجعة قبل التسليم. يجب أن يطلب المحول ما ينقص، ويوقف التحويل إذا فقد صورة أو معادلة أو سؤالًا، ويحفظ الأصل والنسب وبصمته. لا يمرر الإجابات إلى نسخة الطالب. الربط يحتاج اختبارات عزل المعلمين وتخزين النسخ وإدارة حالة المراجعة؛ لم يُفعّل هنا.

`app/exam_rewrite/` في الأساس `cdb57a5` ما زال يُنتج تحليلًا دون PDF مخصص. `app/exam_engine/` يملك تصديرًا مستقلًا؛ هذه الإضافة تتبع بنيته في فصل القالب والتصدير، دون استبدال مساره. الوصول الآلي لتحضيري وترخيص إعادة استخدام ملفاته ضمن خدمة تجارية ليسا نتيجة محسومة لهذه التجربة؛ لا يعني تصميم قوالب أصلية الحصول على ترخيص لإعادة نشر المحتوى المرجعي.
