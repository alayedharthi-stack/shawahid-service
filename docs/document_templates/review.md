# سجل التنفيذ والمراجعة

التاريخ: 22 سبتمبر 2026. الأساس: `cdb57a50ebc013d40a01e3648e5d1ed9ef555b09`. الفرع المحلي: `codex/document-templates-pilot`.

## دورة التشاور المنفذة

جرت المراجعة في محادثة «شواهد Ai — فكرة مساعد المعلم» عبر جلسة Chrome الموجودة، بتفويض تركي للخيارات الروتينية. أُرسلت الملفات والصور فعليًا، وقُرئت الردود قبل التطبيق؛ لم يُفترض اتصال تلقائي بين المحادثتين.

1. عُرض جرد المراجع وحدودها وفصل HTML/JSON عن Word. أقر المراجع A4 وهوامش 14 مم، إخفاء درجات الورقة افتراضيًا، وفصل الإجابات والمدرسة والإدارة الفارغتين، والمسار الاختياري الجديد.
2. أُرسلت ورقة العمل وإجابتها وبياناتها وصور الصفحات. طلب المراجع تقليص الكليشة، تحسين التعليمات ومساحات الإجابة، عزل الرياضيات، تكبير مقام الكسر، إكمال جدول الإجابات وترقيم الرسم والصفحات بالعربية.
3. أُرسلت النسخ المصححة PDF وصور الصفحتين. أُغلقت مراجعة القالب الأول بصريًا وحسابيًا؛ طُبق تصحيح غير مانع لصياغة السؤال السادس. اعتماد العينة لا يثبت مطابقة المنهج.
4. أُرسل الاختبار من صفحتين وإجابته من صفحة والخطة الأفقية من صفحة، مع صور صفحاتها الأربع. أقر المراجع صلاحيتها للإدراج في Draft PR، وطلب رأس تعريف للصفحة الثانية، وتفصيل الدرجة الجزئية للسؤال السابع، وخانة تاريخ لكل يوم وتحسين تقويم الأحد. طُبقت هذه الملاحظات في النسخ النهائية.
5. أُرسلت ملفات PDF المحدّثة وصور الصفحات الثلاث المتأثرة. قُرئ إغلاق المراجع للتصحيحات الثلاث بعد فحصها؛ أُعيدت الاختبارات الـ16 ونجحت في 19.3 ثانية. طلب المراجع رابط Draft PR ومعرف الالتزام النهائي لمراجعة الكود والنطاق؛ إغلاق المعاينات لا يمثل اعتمادًا للكود.

هذه مراجعة تصميم من المساعد المفوض؛ الدمج والنشر وتفعيل الخدمة ما زالت لقرار تركي. الاختبارات شُغّلت محليًا بواسطة منفذ التجربة؛ المراجع لم يدّع إعادة تشغيلها.

قناة الرفع: اتصال GitHub البرمجي أعاد `Resource not accessible by integration` عند إنشاء الفرع، وتسجيل CLI القديم لم يكن صالحًا. واجهة GitHub في جلسة Chrome كانت مسجلة بحساب المالك وتعرض إنشاء فرع ورفع ملفات؛ استُخدمت هذه الواجهة العادية ضمن طلب تركي الصريح للعمل بالمتصفح وفتح Draft PR. لم تتغير صلاحيات التكامل أو سياسات المستودع، ولم يُدخل رمز وصول أو تُجمع بيانات دخول. نُفذت التزامات الرفع على الفرع المستقل فقط.

## ما جرى فحصه

| الناتج | الصفحات | التحقق |
|---|---:|---|
| ورقة الطالب | 1 | ثمانية أسئلة أصلية، RTL بعمودين، الطرح والكسر، صورة أصلية وجدول، بلا حلول أو حقول درجات ظاهرة |
| إجابة الورقة | 1 | ثمانية حلول صحيحة؛ جدول القيم 7 و9 و12، وحل مسألة العلب 9 أقلام |
| الاختبار | 2 | البنود 1–4 ثم 5–8؛ مجموع 10؛ رأس استمرار واسم طالب في الصفحة الثانية؛ لا انقسام لسؤال |
| إجابة الاختبار | 1 | منفصلة؛ نصف درجة لكل من القيم الثلاث ونصف لتحديد س في السؤال 7؛ درجة للمعادلة وأخرى للحل في السؤال 8 |
| الخطة الأسبوعية | 1 أفقي | خمسة أيام، ستة أعمدة، تواريخ فارغة قابلة للتعبئة، سطرا ملاحظات |

فُتح كل PDF ورُسمت جميع صفحاته وفُحصت بصريًا. فُحصت النسخة الأخيرة من كل صفحة متأثرة بالتعديل. المقارنة هنا بين البيانات الأصلية التي أُنشئت للتجربة والناتج وبين نسخ القالب أثناء التصحيح؛ **ليست مقارنة تطابق مع أسئلة أو تصميم المرجع التجاري**، إذ لم تُنقل تلك الأسئلة أصلًا.

اجتازت اختبارات العقد والتصدير الحقيقي: 16 اختبارًا (12 للعقد والرياضيات و4 للتصدير). تشمل التصدير الفعلي للعينات الخمس، عدد الصفحات وأبعادها ووجود الصور والخطوط وعدم الصفحة الفارغة، و24 سؤالًا لكل من الورقة والاختبار مع تعقب بداية ونهاية محتوى كل سؤال عبر الصفحات، ورفض الصورة التالفة والكتلة الأطول من الصفحة. اجتازت أيضًا اختبارات محرك الاختبارات الحالي: `pytest --noconftest tests/test_exam_engine.py -q`، عددها 32. لم يُشغّل كامل اختبار الخدمة أو ربط واتساب/قاعدة البيانات.

البيئة: Python 3.12.10، Jinja2 3.1.4، Playwright 1.44.0/Chromium 1117، PyMuPDF 1.25.5، Windows. استغرق أول تشغيل كامل للاختبارات الـ16 نحو 17.9 ثانية، واختبارات المحرك 0.93 ثانية؛ هذه أزمنة الاختبارات وليست إجمالي وقت العمل. لا شراء أو API توليد مدفوع ضمن تصدير القوالب؛ لا تتوفر تكلفة معزولة لاستخدام الاشتراكات والمحادثة.

## ما بقي قبل الاستخدام الفعلي

مطابقة الفصل وطبعة المنهج، بيانات المدرسة والإدارة، وتجربة المعلم الواقعية لم تثبت بعد. لا تحويل DOCX، ولا استيراد كامل تلقائي لصور PDF أو معادلاته، ولا واجهة تحرير مرئية. حفظ النسخ وربط المراجعة والتسليم غير مفعّلين. شروط إعادة استعمال أسئلة تحضيري/واجباتي ضمن خدمة للغير تحتاج حسمًا مستقلًا؛ لم يُنسخ هذا المحتوى أو شعاراته إلى القالب العام.
